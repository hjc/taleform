q01-todays-model-as-data.html grilling At its simplest, what is each of Mission, Act, Beat, Encounter, NPC, Arc and Campaign: which are kinds of note, which are relations or groupings, and which are blocks inside a note?

The developer wants the core concepts settled first: "What is a mission at its base layer? What is an NPC? What is an encounter?" Today a mission is kind: mission, membership is the mission link, and acts and beats are sequence kinds ordered by act/beat numbers. An encounter is only an Initiative Tracker encounter block summed against stat blocks. NPCs are not modelled at all. Arc and Campaign are named in CLAUDE.md but not designed, and this effort models them without building their maps. Run with domain-modeling; every answer is a row in the vocabulary.
